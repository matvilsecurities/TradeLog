# Phase 12 — Responsive UX & Mobile Workspace

## Scope
- Responsive navigation drawer for tablet/mobile widths.
- Mobile navigation overlay and touch-sized controls.
- Dense tables retain horizontal scrolling instead of collapsing columns.
- Modals become full-width bottom sheets on narrow screens.
- Dashboard grids collapse to a single column on narrow screens.
- Reduced-motion support for the responsive drawer.

## Preservation
- No database changes.
- No trade calculation changes.
- No Supabase/auth changes.
- Desktop sidebar remains unchanged at normal widths.
