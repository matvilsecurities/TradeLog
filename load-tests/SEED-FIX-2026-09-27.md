# Seed fix — 2026-09-27

The first seed attempt exposed a schema mismatch in the load-test seed: the staging `accounts.id` returned by the existing database is numeric, while the production RPC treats optional `account_uuid` as UUID. The corrected seed intentionally omits `account_uuid` and lets the RPC resolve ownership from `account_id` for the authenticated user.

Existing `primary` accounts created by the first attempt are reused. Re-run the seed after replacing the project with this build; it should create the requested trades without recreating accounts.
